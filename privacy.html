プライバシーポリシー

raspi4 Dashboard は、運営者本人が利用する個人用アプリです。本ポリシーは、このアプリおよび紹介用公開サイトのデータの取り扱いを説明します。

1. 取得する情報と目的

本人の同意に基づき、Google Calendar API と Google Tasks API を読み取り専用で使用します。

  • Calendar：対象カレンダーの直近の予定を取得し、タイトル、開始・終了日時、終日指定、予定へのリンクなどを表示します。
  • Tasks：対象リストの未完了タスクを取得し、タイトル、期限日、リスト名を表示します。
  • OAuth 認証情報：継続取得に必要な更新トークン等を保持します。Google のパスワードは取得・保存しません。

API 応答には表示対象以外のフィールドが含まれる場合がありますが、アプリは表示に必要な項目を抽出します。目的は本人による予定・タスクの確認と残り時間の表示のみです。予定・タスクを変更する機能はありません。

2. 保存先・保持期間・保護

取得した Google の予定・タスクは、運営者管理下のサーバーのメモリと、表示する端末のブラウザー上で扱います。現在の実装では履歴データベースへの保存は行いません。取得失敗時には、最後に取得した情報を古いデータとして保持・表示する場合があります。サーバープロセスの停止・再起動およびブラウザーのページを閉じることで、それぞれのメモリ上の情報は失われます。

OAuth 認証情報はサーバー上のアクセス権を制限したファイルに保存し、連携解除まで保持します。Google との通信とブラウザーからのダッシュボード接続は HTTPS、初回設定のサーバー転送には SSH を使用します。ダッシュボードの閲覧は家庭内ネットワーク・許可した VPN に制限します。認証情報はダッシュボードのブラウザーや紹介用公開サイトには配信しません。

3. 第三者提供・AI への利用

Google から取得した予定・タスクを販売せず、広告目的や AI モデルの学習・推論に利用せず、AI ベンダーや GitHub Pages に送信しません。Google API との認証・取得通信を除き、このアプリが当該データを外部サービスへ転送する機能はありません。Google Calendar・Tasks へのリンクを開いた場合は、Google のサービスとポリシーが適用されます。

raspi4 Dashboard による Google API から受領した情報の使用および他のアプリへの転送は、限定的な使用（Limited Use）の要件を含む Google API Services User Data Policy に準拠します。

4. 連携解除・データ削除

Google アカウントの接続管理で、このアプリへのアクセス権を取り消せます。運営者はサーバーの Google 連携認証ファイルを削除し、ダッシュボードサービスを再起動することで、保存した認証情報とメモリ上の取得データを削除できます。表示中のブラウザーページも閉じてください。これらの操作によって Google 側の予定・タスクが削除されることはありません。

5. 紹介用公開サイト

この公開サイトは静的な説明ページです。独自のアクセス解析、広告、フォーム、Google ログイン機能は設置していません。ホスティング事業者の GitHub は、サイト配信に伴い IP アドレス等を処理する場合があります。詳しくは GitHub のプライバシーステートメントをご覧ください。Google Calendar・Tasks のデータや OAuth 認証情報は公開リポジトリに含めません。
